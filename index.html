Write the script. It plays the part.

Where the cloned voices come from

    Files

    Pick the memory your card has.

    Each file holds the whole model, and all four complete the same share of our test takes. They differ in how the routed experts, 90% of the model, are stored. Every one needs the 1.6 GB codec beside it.

    FileWhen to take itSizeSystem RAM24 GB12 GB8 GB

    Speed is a multiple of real time on an RTX 4090, with the fastest file for each card in amber. How close each file stays to FP8, and how it was measured, is in the README.

    Install

    Three steps to the first take.

    1. Install the nodes

      Search for Drama 3 text to speech in ComfyUI-Manager, run comfy node install drama3, or clone the repository. Then restart ComfyUI.

      cd ComfyUI/custom_nodes
git clone https://github.com/PedroMarinhoDev/ComfyUI-Drama3

    2. Download a model and the codec

      FP8 suits a 24 GB card; on a smaller one, pick another file. Voice cloning also needs the Qwen3-ASR file in models/asr.

      hf download PedroMarinhoDev/Drama-3-ComfyUI drama3_fp8experts_bf16.safetensors --local-dir ComfyUI/models/diffusion_models
hf download PedroMarinhoDev/Drama-3-ComfyUI drama3_codec.safetensors --local-dir ComfyUI/models/vae

    3. Open a workflow and queue

      Drag drama3_voice_clone.json into ComfyUI, pick a clip of clean speech and write your text. The README explains directions, dialogue and what to do when a take goes wrong.
